Intructivo para correr la demo en un emulador:

Requisitos previos:
- Sistema Operativo: Android 11.0 (API 30) o superior.
- Archivos requeridos: demo_parkinson.apk
- Health Connect con datos o Health Connect Toolbox.

En caso de tener Health connect Toolbox:
1. Hacer click en "Request All Permissions".
2. Cargar datos de pasos, distancia, sesiones de sueño y frecuencia cardiaca.
  
1. Descargar la apk en un dispositivo Android o emulador.
2. Presione el archivo .apk descargado para iniciar la instalación
3. Si el sistema Android muestra el mensaje "Por seguridad, tu teléfono no tiene permitido instalar apps desconocidas de esta fuente":
    - Seleccione Ajustes / Configuración.
    - Active la casilla Permitir desde esta fuente.
    - Regrese y presione Instalar.
4. Una vez instalada, abrala una vez.
5. Cierre la aplicación y dirijase a configuración/apliaciones
     - Hacer click en la app demo
     - Ir hacia permisos
     - Permitir acceso a Health Connect
6. Una vez concedidos los permisos ya se puede usar y probar la demo.
